# Responsive Calculator

A lightweight, responsive browser calculator built with plain HTML, CSS, and JavaScript. No frameworks, dependencies, build tools, or server are required.

## Features

- Addition, subtraction, multiplication, and division
- Decimal and percentage operations
- Parentheses and unary sign changes
- Clear and delete controls
- Keyboard support
- Responsive layout for desktop and mobile
- Safe arithmetic parser (does not use `eval()` or `Function()`)

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

No installation is required.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| 0–9 | Enter digits |
| `+`, `-`, `*`, `/` | Arithmetic operators |
| `.` | Decimal point |
| `%` | Percentage |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last character |
| `Escape` | Clear |

## Notes

This is a client-side demonstration calculator. It does not store calculation history or send data to a server.
